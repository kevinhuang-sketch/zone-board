# 分區指派板 Zone Board

在自己上傳的地圖截圖上圈出分區、指派負責人,再把整張圖匯出成 PNG。

**線上使用:** https://kevinhuang-sketch.github.io/zone-board/

## 怎麼用

1. `⌘V` / `Ctrl V` 貼上今天的地圖截圖(或把圖檔拖進來)
2. 右邊建好**負責人**名單 —— 可以直接從 Excel 整欄貼上(`1. 王小明` 這種編號會自動去掉),再點一個人設成「畫這個」
3. 在地圖上圈區域 —— 圈完直接圈下一塊,不會跳任何對話框
4. 要補區域名稱就雙擊區塊,不補的話標籤只顯示人名
5. 按**匯出圖片** → 下載 PNG 或直接複製到剪貼簿

## 名單整批匯入

負責人那格支援直接貼上多行文字,這些格式都吃得下:

```
1. 王小明        (1) 王小明        5→王小明(編號在隔壁欄)
2、林小華        林小華, 陳大文, 張美玲
```

重複的名字會自動跳過並告訴你跳過幾個。貼錯了按 ⌘Z 可以整批復原。

## 設計上的兩個決定

- **顏色跟著「人」走,不是跟著「區」走。** 同一個人負責的所有區塊都同色,整張圖不用看字就知道誰的地盤多大。
- **人留著、區清掉。** 負責人名單存在瀏覽器裡跨天保留;貼上新底圖時只清空分區,因為分區每天都是重畫的。

## 快捷鍵

| 鍵 | 動作 |
|---|---|
| `1` `2` `3` | 切換多邊形 / 矩形 / 手繪 |
| `4`–`9` | 直接切換負責人 |
| `⌘Z` | 上一步(圈到一半時是「退一點」) |
| `Enter` | 收尾目前的多邊形 |
| `Esc` | 取消目前的圈選 / 取消選取 |
| `Delete` | 刪除選取的分區 |
| 方向鍵 | 推動選取分區的標籤位置 |
| 雙擊名字 | 原地改名(負責人、區域名都可以) |

## 關於資料

**沒有後端,也沒有任何東西會上傳。** 你貼上的截圖、畫的分區、負責人名單全部只存在你自己的瀏覽器裡。
負責人名單和偏好設定用 `localStorage` 保存,清掉瀏覽器資料就會消失。

## 自己跑

單一 HTML 檔,零相依套件。把 `index.html` 存到本機雙擊就能開,不需要任何伺服器。
(用 `file://` 開的時候,「複製到剪貼簿」不一定能用,但下載 PNG 可以。)
